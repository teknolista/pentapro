## Finding V1 — differential harness cannot enforce the identity it asserts (blocking PROOF)

`test/differential.py` lines 13–15 directly resolves arbitrary paths from `sys.argv` and executes them. It does not check upstream Git SHA, record upstream build identity, or record Node version, contrary to PROOF's explicit requirement to verify the exact SHA and record Node/build identity. A different reference can silently be compared and pass. The current manual checks establish these identities for *this run only*; they do not satisfy the committed harness guarantee. Remedy: explicitly derive and verify reference checkout SHA and expected executable/build identity, record Node and binaries; test refusal on a wrong checkout/identity. Record trust limitations: SHA of checkout alone does not establish that `dist/` was built from it.

## Finding V2 — external directory symlink confidentiality/contract interpretation

Independent temporary fixture: `openspec/specs/alpha` is a directory symlink to an external directory containing a sentinel `spec.md`; `show alpha --type spec --json` returned exit 0 and the outside sentinel for both Engine and upstream. PRODUCT simultaneously says 'Reject absolute paths, traversal and path escapes' and 'explicitly shown directory links work as observed'. The latter does not clearly state that *external* directory links may disclose arbitrary readable external files, and only internal directory links were observed in cited baseline boundary cases. Therefore this is an unresolved specification/safety decision, not conclusive parser incompatibility: explicitly decide whether outside-directory symlinks are forbidden (declared upstream divergence) or permitted and document the trust boundary and concrete scenario; then align implementation and tests. A path's compatibility with upstream does not settle security acceptance.
