## Delivered source contracts

Existing six factory roles remain; all 36 packaged adapters and six tracked Copilot profiles carry relevant new contracts while preserving metadata. Full-source instruction review, preservation and evidence distinctions follow the permanent manifesto; the experiment does not establish a motivational benefit.

Scope inventory now includes operational tools, data lifecycle, development/installed/automated contexts and experience. Criteria name owner, observable and evidence. Packets carry bounded scope, environment facts, prior receipts, decisions and real stop conditions. Authorized repair continues within the current phase. Alternatives consider maintenance and proof costs. Core gates and independent review remain; old receipts retain their original snapshots.

New helpers are optional: POSIX command evidence captures actual status/timeout without raw output/arguments; the setup section planner proposes canonical permanent sections without writing a project file. Setup and migration preserve conflicts, custom settings, histories and index selections. There is no new updater engine, telemetry service, supervisor, mandatory extra form or global hook.
